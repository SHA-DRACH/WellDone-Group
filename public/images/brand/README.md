# Brand assets

Drop the official WellDone Group Inc. logo files here. The application looks
for these exact filenames, and every surface (site header, footer, admin
panel, sign-in screen, favicon, page banners and email templates) picks them
up automatically.

| File              | Used for                                            | Recommended                          |
|-------------------|-----------------------------------------------------|--------------------------------------|
| `logo.png`        | Site header, footer, admin sidebar, sign-in, emails | Square or near-square, ≥ 512 px, transparent background if possible |
| `logo-mark.png`   | Favicon and small badges (optional)                 | Square, 512 × 512 px                 |
| `logo-light.png`  | Optional variant for dark backgrounds               | Same dimensions as `logo.png`        |

`logo.png` is the only required file — the others fall back to it.

## Replacing the logo later

You do not need to touch these files after launch. An administrator can
upload replacements from **Admin → Website Settings → Company**, which stores
them on the public disk and overrides whatever is in this directory.
